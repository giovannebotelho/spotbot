# 🤝 Como Contribuir para o SpotBot Pro

Agradecemos o interesse em contribuir com o **SpotBot Pro v3.0 (Hedge Fund Edition)**!

Este é um projeto quantitativo focado em alta taxa de vitória, microestrutura de mercado e modelos de inteligência artificial.

---

## 📋 Como Submeter Melhorias (Workflow)

1. **Fork do Repositório**: Faça o fork do projeto para sua conta do GitHub.
2. **Crie uma Branch**: `git checkout -b feature/minha-melhoria-quant`
3. **Desenvolva e Teste**: Garanta que seus testes automatizados ou scripts em `scratch/` passem sem erros.
4. **Commit Limpo**: Escreva mensagens de commit claras (ex: `feat: novo scanner de volatilidade`).
5. **Pull Request**: Abra um PR detalhando a lógica matemática e os resultados esperados.
